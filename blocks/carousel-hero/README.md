# carousel-hero

Custom **carousel** block. Purpose: full-bleed rotating promo banner of image-only slides with a control bar (prev, dots, next) below.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per slide: [image | text with a CTA link]. The link covers the whole slide; its text is visually hidden because the artwork carries the message.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
